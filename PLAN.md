# Ausbau zum Funktionsumfang des Wettbewerbs

Arbeitsliste, abgeleitet aus den Bildschirmen von POCASIO. Sie wird von oben
nach unten abgearbeitet; die Reihenfolge folgt den Abhaengigkeiten, nicht dem
Aufwand. Erledigtes wird abgehakt und bleibt stehen, damit nachvollziehbar ist,
was schon steht.

## 1. Seitenleiste und Gliederung — erledigt

- [x] Linke Navigationsleiste mit Gruppen, aufklappbar
- [x] Auf dem Telefon als Schublade hinter dem Hamburger, mit Abdunkler
- [x] Aktiver Eintrag hervorgehoben
- [x] Projektuebersicht als Startseite: Budget, geplante Kosten,
      Auftragssumme, Mehrkosten, Restbudget, naechster Arbeitsschritt,
      offene Maengel mit Fristwarnung, Stand des Tagebuchs
- [x] Offene To-Dos und Fortschritt des Bauleitfadens nachgezogen

## 2. Bauleitfaden — erledigt

- [x] Sechs Phasen von der Finanzierung bis zur Uebergabe
- [x] Vierundsechzig Punkte je mit Begruendung, zum Abhaken, Fortschritt je
      Phase und gesamt
- [x] Schritt-fuer-Schritt-Ansicht neben der Gesamtliste
- [x] Verweise aus den Punkten in die passenden Bereiche
- [x] Fortschritt auf der Projektuebersicht

## 3. Baukosten aufteilen — erledigt

Heute steckt alles in der Baukasse. Der Wettbewerb trennt es in vier Sichten,
und das ist die bessere Ordnung.

- [x] Budgetplanung: Gesamtbudget, Wohnflaeche, Budget je m2, Geldmittel mit
      verwendet und offen, Zahlungsverlauf je Monat
- [x] Kostenaufstellung: Tabelle mit Sortierung, Filter, PDF und CSV
- [x] Statistiken: je Status, je Gewerk, je Kostengruppe, Geldmittelverteilung
- [x] Angebotsvergleich bleibt eigen
- [x] Nebenbei: der Router kann Unterwege, damit Ansichten einzeln in der
      Leiste stehen

Die Ausgabe fuer Excel laeuft ueber CSV. Eine echte xlsx-Datei steht in
Schritt 10.

## 4. Angebote vertiefen — erledigt

- [x] Positionsvergleich: je Taetigkeit eine Leistung, ankreuzen welcher
      Anbieter sie angeboten hat. Genau daran scheitern Vergleiche in der
      Praxis.
- [x] Warnung, wenn das guenstigste Angebot weniger abdeckt als ein teureres,
      samt Liste dessen, was fehlt
- [x] Leistungsumfang steht auch im Vergleichs-PDF
- [x] Angebot in die Kostenaufstellung uebernehmen (stand schon)

## 5. Kontakte aufteilen — erledigt

- [x] Firmen, Privatpersonen und Gewerke getrennt, jedes einzeln in der Leiste

- [x] Umbenennen zieht Positionen, Maengel und Kontakte mit
- [x] Loeschen nur, solange nichts daran haengt

## 6. Organisation — erledigt

- [x] Offene To-Dos auf der Projektuebersicht (der offene Punkt aus Schritt 1)

## 7. Dokumentation ergaenzen — erledigt

## Was BauZeuge schon hat und der Wettbewerb nicht

Nicht aus den Augen verlieren, das sind die Unterschiede, die verkaufen:

- Anschlussplan auf dem Grundriss
- Raeume als eigene Einheit mit Kosten je m2
- Gliederung nach DIN 276
- Wetter vom Deutschen Wetterdienst im Tagebuch
- Vollstaendig offline nutzbar
- Kein Abo-Zwang fuer den Zahlungsverlauf
